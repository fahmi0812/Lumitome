## 0.3.39 — Fallback GitHub API untuk lumitome update

- Akar masalah (P0-1 dari deep-check bottleneck Anthropic, terverifikasi dari kode + reproduksi): `lumitome update` memeriksa versi terbaru dengan `git ls-remote --tags`; bila git tidak ada di PATH (umum di instalasi npm Windows tanpa Git for Windows), spawn gagal ENOENT — tapi pesan menyalahkan internet ("Cek koneksi internet, lalu coba lagi"). Reproduksi di VM dengan PATH tanpa git: pesan persis sama, log menulis `ERROR: spawn git ENOENT`. Kelemahan yang sama persis dengan 0DayExploit sebelum v0.9.2.
- Perbaikan (port pola 0DayExploit v0.9.2, di `lumitome/lib/update.mjs`): baru `parseRepoSlug`, `latestReleaseTag`, `isGitMissing`. Bila `ls-remote` gagal karena git tidak ditemukan: mode npm jatuh ke GitHub API `GET /repos/fahmi0812/Lumitome/releases/latest` (tanpa git sama sekali, tanpa token) untuk mendapatkan tag terbaru; bila API juga mati, pesan menyebut "git tidak ditemukan" + perintah update manual (`npm install -g <tarball>`), bukan "cek internet". Mode git (butuh git untuk clone) gagal dengan pesan yang menyebut Git for Windows, tanpa fallback API. Cek `ls-remote` kini juga punya timeout eksplisit 30 detik (sebelumnya bisa menggantung). Jalur verifikasi SHA/VERSION + swap atomik + rollback tidak diubah.
- Tes (cara mattpocock TDD: 4 tes baru ditulis dulu — merah sebelum fix, hijau sesudahnya): npm-mode tanpa git → fallback API + instalasi tarball jalan; npm-mode tanpa git + API mati → pesan menyebut git + perintah manual; git-mode tanpa git → gagal jelas + Git for Windows, API tidak dipanggil; `parseRepoSlug` https/git@/ssh + null non-GitHub. Terverifikasi LIVE tanpa git (PATH tanpa git, API sungguhan): versi lama 0.3.37 menemukan v0.3.38, versi 0.3.38 "Sudah versi terbaru", git-mode menampilkan pesan Git for Windows. Validate OK (warns 0), test **367/0** (363 lama + 4 baru).
- Catatan penting: fix ini TIDAK bisa sampai lewat `update` yang rusak itu sendiri — pengguna yang updater-nya sudah rusak harus update manual sekali (`npm install -g https://github.com/fahmi0812/Lumitome/tarball/v0.3.39`) atau instal Git for Windows, baru updater jalan normal.
